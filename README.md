
# Book A Doctor

Book A Doctor is a full-stack MERN application for booking medical appointments, managing doctor profiles, handling patient reports, and supporting role-based dashboards for patients, doctors, and admins.

## Features
- JWT-based authentication and role-based authorization
- Patient, doctor, and admin dashboards
- Doctor discovery with search and filtering
- Appointment booking and management
- Secure file upload for reports
- Admin tools for managing users, doctors, and approvals

## Tech Stack
- Frontend: React, Vite, React Router, Axios, Bootstrap, React Icons
- Backend: Node.js, Express, MongoDB/Mongoose, JWT, bcrypt, Multer

## Project Structure
- client/ for the React frontend
- server/ for the Express backend

## Setup
1. Copy server/.env.example to server/.env and update the values.
2. Install dependencies:
   - cd server && npm install
   - cd ../client && npm install
3. Start the backend:
   - cd server && npm run dev
4. Start the frontend:
   - cd client && npm run dev

## Environment Variables
See server/.env.example for the required keys.
